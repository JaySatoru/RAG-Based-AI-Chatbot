# RAG-Based-AI-Chatbot
An AI-powered chatbot built using Retrieval-Augmented Generation (RAG) that answers user questions based on information extracted from uploaded PDF documents. It uses LangChain, Ollama (Llama 3.2), Nomic Embeddings, and ChromaDB to retrieve relevant info from documents and generate context-aware responses. It provides interactive UI i.e. Streamlit.
